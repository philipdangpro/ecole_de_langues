# NoSQL — L6 (sharding MongoDB) et L7

Responsable : à définir

- `mongodb/` : collection shardée (L6, clé justifiée par la répartition mesurée) et usage L7.
- `moteur2/` : second moteur pour L7 (renommer le dossier : redis, neo4j, cassandra, elasticsearch…).

Pour chaque moteur : besoin réel de la plateforme, modèle orienté requêtes, script d'import des données, trois requêtes.
